# Location Stock Indicator 利用者ヘルプ

関連要件 #20。サイト側の対応パスは /help/location-stock-indicator/ 。

## 導入・通常操作・例外
- 初期設定では利用条件、必要な権限、動作確認方法を記録する。
- 通常操作の対象は「来店前に、欲しい色・サイズの在庫がある店舗を調べる。」。導入者視点の手順と期待される結果を合成データで確認する。
- 症状別の初稿「店舗在庫が商品ページに表示されない」
  1. 商品とバリエーションを特定し、対象店舗の販売可能数を確認します。
  2. 別の色に切り替えて表示を比較し、店舗の表示設定とテーマ上のアプリブロックを確認します。取得に失敗した表示から欠品とは判断できません。
  3. 同じバリエーション・店舗の販売可能数と表示が一致するか照合します。

## 変更時の確認
画面や手順の変更時は、アプリの変更PRから該当するサイト記事の差分を参照する。対象版、実際の画面名、操作結果、再試行可否を確認した上で案内する。上記は初稿であり実機確認済みの手順ではない。
