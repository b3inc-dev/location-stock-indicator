# Ciara 店舗の Shopify POS Lite 対応要件

## 対象と既存実装
対象はCiara自社配布版。ストア管理者が機能と対象ロケーション・倉庫を設定し、現場はPOSのみで操作する。POSログイン1人分、返金・値引きは全員可能。公開版の提供プラン・料金は今回の変更対象外。
- Location Stockのテーマ拡張は受取可能店舗の表示とカート追加まで。受取店舗の正本はチェックアウト後のShopify出荷指示。docs/STORE_PICKUP_BUTTON.md参照。従来の自社版スコープに受取処理権限はない。
- POS Receiptは既に特殊返金、返金計上店舗、商品券調整と精算注文の発送済み化を担当。新しい返金機能は作らない。既存の精算注文処理と新しい通常会計処理を重ねない。
- Ciaraのlib/shopify/sync/upsert-order.tsは明細のattributed_staffsを取り込み、line-item-attribution-sync.tsは入力に無い帰属を削除する。独自属性を付けるだけでは個人実績にならない。
- POS Stockがロケーション間の物理移管を担当。配送注文の出荷元割当と物理移管を区別する。

## Location Stock 店舗受取
POSタイルに現在店舗の実受取注文を表示。Shopifyの割当ロケーションとdeliveryMethod=PICK_UPを照合。注文番号、商品、数量、準備待ち・引渡待ちを表示。転送待ち・保留・キャンセルは実行不可。準備完了でShopify標準通知を1回送信。来店時に注文を確認し引渡完了。二端末連打・再起動時はShopifyから最新状態を取得し、二重通知・二重履行を避ける。引渡完了と標準受取済みメールの挙動は個別に確認。スタッフに管理画面操作を求めない。

## Location Stock 店頭配送・通常会計
店舗ごとに初期OFF。出荷元・送料規則を設定。POSの自動履行OFFが揃った対象端末で使用する。配送OFFはタイルを開かず通常会計。配送ONは会計前に配送先・連絡先・送料・出荷元、商品別配送数量を検証。送料は決済総額・領収書・精算に一致させる。住所は必要な注文/出荷記録に保存し公開明細属性に複製しない。カートと商品を配送受付IDで照合し、明細変更・削除・配送取消時は送料と数量を再計算する。
支払完了と出荷指示の割当を確認して実行。販売店舗、POS販売元、対象機能の有効期間を確認。EC、受取、下書き、精算・点検、返品・交換、取消、既に完了した数量を除外。独自の受付情報が一部だけ存在する注文は例外一覧へ。既存の他アプリやCiara受注管理と同じ明細を二重発送しない。
配送数量だけ倉庫に割当。現在の出荷指示を取り直し、持ち帰り分だけ販売店舗で履行（発送通知なし）。全点配送時は店頭履行0。倉庫の出荷待ちと送り状に配送先・数量・出荷元が揃い、発送時だけ追跡番号と通知を登録。売上店舗と担当者は元注文に維持。在庫を手動減算して二重引当しない。
Webhook受信を永続化し、店舗・注文・明細別に処理。重複・逆順、処理中断、移動済み/履行済みを再読込して再開。欠品・決済後の配送取消・情報不備をPOSの要確認一覧に表示し、再処理時は残数だけを対象とする。オフライン販売の注文到着遅延、決済完了前の受付情報の保存を確認する。

## POS Receipt / Ciara システム
既存スタッフマスタの本人IDを対応付ける。ログイン担当とは独立して一括設定・商品ごとの変更、同一明細の人数別数量を扱う。署名などで自社POS由来をサーバーで検証し、ECの任意入力を個人実績に採用しない。過去の標準帰属を保持し、Liteは対応付けたIDを同じ個人実績に集計する。通常・一括・欠損再取込で同じ結果。部分返品時の売上訂正は元明細へ。レシートとCiara日報も照合。
他店・EC購入の現金返品は既存仕様。元決済への二重返金なし、受付店舗で一度だけ現金減算。同店返品は既存ルール。Wespo 3,870円・釣銭なし商品券7,920円・返品済未返金6,831円を回帰確認。

## 切替判定
Lite実機で通常・全点配送・混在・同SKUを1点ずつ・倉庫欠品・受付後の数量変更・支払中止・再送・2端末の受取を照合。受取通知、店頭引渡し、倉庫の実出荷、送料、店舗/倉庫在庫、精算・スタッフ実績まで確認。配送先が既存倉庫システムの読み取る場所に渡ることを確認。現行のVIP/ポイント適用とmPOP・mC-Print3の発行/再発行もLiteで確認。POS Pro標準の自動割引と高度なレシート設定への依存が残れば該当業務を先に補う。
試験店舗で開始日時を記録し、通常会計の未処理一覧を監視する。停止時は新規注文の対象期間を閉じて従来の端末設定に戻し、期間内の支払済み未処理分は個別に照合する。
