## 1. App name (≤30)

```
Location Stock
```

## 2. App card subtitle

```
Show shoppers which of your stores has the item in stock
```

## 3. App introduction (≤100)

```
Show stock by store on product pages, so shoppers know where to buy or pick up today.
```

## 4. App details (≤500)

```
For shops with several stores or warehouses. Show stock for the selected variant at each location on the product page.

Show stock as In stock, Low stock or Out of stock, or as a number. In admin, set the thresholds and labels, choose locations, and set their names and order. You can list locations with shipping, local delivery or pickup first.

On Pro, group stores by area, show the store nearest to the shopper, and add a pickup button. Add the block in the theme editor. No theme code changes.
```
（499 characters。空白と改行も数えた）

## 5. Key benefits

1. Shoppers see where the item is in stock, right on the product page.
2. Help shoppers visit or pick up at a nearby store (Pro).
3. Match your store: labels, thresholds, order and which locations to show.
4. No theme code changes: add one block in the theme editor.
