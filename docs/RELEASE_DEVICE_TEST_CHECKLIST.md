# RELEASE_DEVICE_TEST_CHECKLIST.md — 次回リリースの実機テスト表（Issue #20）

Issue #20 の受け入れ条件のうち、実機でしか確かめられないもの（各プラン × 公開版／自社版、複数テーマ、PC／スマホ、ブロックの削除と再追加、アンインストール後に何も残らないこと）を T が手で確かめるための表。

- この表は**テストの手順**であって、マージ・デプロイ・課金・審査提出の許可ではない。
- 課金が発生する操作（本番ストアでの有料プラン承認）は、別に T が承認するまでしない。開発ストア（`bbbincbbb`）のテスト課金と `FORCE_PLAN_LITE=1`（`docs/PLAN_SETTINGS_DESIGN.md`）で確かめる。`FORCE_PLAN_LITE` は確認後に必ず外す。
- 開発ストアの Pro 相当の動作だけで「公開未契約」「Lite」の合格にしない（#20 §1）。
- 結果を公開 Issue に書くときは匿名にする（ストアのドメイン・実店舗名・在庫数・トークンを書かない）。
